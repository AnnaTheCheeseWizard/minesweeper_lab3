# Сапер із розумним розв'язувачем та кастомізацією (Android, Kotlin)

Сучасна реалізація класичної гри «Сапер» (Minesweeper) для Android із вбудованим алгоритмом штучного інтелекту (Solver), розширеними візуальними темами, кастомізацією прапорців, відстеженням рекордів та повною підтримкою інтернаціоналізації.

---

## Ключові можливості проєкту

- **Чесна логіка та безпечний старт**:
  - Перший хід завжди 100% безпечний (міни генеруються після першого дотику, створюючи відкриту зону).
  - Автоматичне відкриття порожніх областей (Flood Fill).
  - Підтримка швидких ходів (Chording) — подвійний дотик по відкритому числу відкриває всіх прихованих сусідів, якщо встановлено належну кількість прапорців.
  - 3 класичні рівні складності: **Новачок** (9×9, 10 мін), **Середній** (16×16, 40 мін) та **Експерт** (16×30, 99 мін).

- **Інтелектуальний Solver (AI-помічник)**:
  - Працює **чесно**, аналізуючи лише той стан поля, який бачить гравець (`BoardSnapshot`), без «підглядання» під приховані клітинки та ігноруючи можливі помилкові прапорці гравця.
  - **3 режими роботи розв'язувача**:
    - **Підказка** (*Hint*) — візуальне підсвічування клітинок на полі (зелений — безпечний хід, червоний — міна, жовтий — розрахований здогад) з детальною текстовою підказкою.
    - **Крок** (*Solve step*) — автоматичне виконання одного безпечного ходу або серії впевнених дій.
    - **Авто** (*Auto-solve*) — повноцінне автоматичне проходження гри з наочною затримкою між кроками.

- **Дизайнерські теми та кастомізація**:
  - **5 колірних тем поля**:
    - *Pond of Lilies* (Латаття) — природні зелені та рожеві відтінки.
    - *Plum & Olive* (Слива та Олива) — глибокі сливкові та оливкові тони.
    - *Cotton Candy* (Цукрова Вата) — ніжний пастельний бордово-м'ятний стиль.
    - *Silk Touch* (Шовковий Дотик) — вишукана синьо-бузкова палітра.
    - *Lavender & Mint* (Лаванда та М'ята) — свіже поєднання трав'яного та лавандового кольорів.
  - **Динамічна адаптація UI**: панель інструментів (Toolbar), картки статистики (міни, таймер, найкращий результат) та кнопки керування автоматично змінюють свій дизайн відповідно до обраної теми.
  - **Вибір кольору прапорців**: можливість обрати власну колірну гаму для прапорців (синій, червоний, зелений, жовтий, рожевий, білий, чорний) або використовувати колір за замовчуванням для обраної теми.

- **Статистика та чесні рекорди**:
  - Відстеження та збереження найкращого часу проходження в секундах для кожного рівня складності.
  - Фіксація рекорду здійснюється **виключно для чесних ігор** (якщо під час партії не використовувалися підказки чи допомога Solver-а).

- **Сучасний UI та адаптивність**:
  - Власний кастомний Canvas-компонент (`BoardView`) для малювання та оптимізованого масштабування поля.
  - Зручне керування жестів (`GestureDetector`): один дотик — прапорець, подвійний дотик — відкриття/акординг.
  - Вібраційний відгук (Haptic Feedback) під час взаємодії з клітинками.
  - Збереження стану гри та таймера при повороті екрана або зміні налаштувань (`GameViewModel`).

- **Багатомовність та RTL**:
  - Підтримка англійської (English), української (Українська) та івриту (עברית).
  - Повна підтримка макету справа наліво (RTL) для івриту.
  - Динамічне перемикання мови безпосередньо з меню застосунку.

## Відповідність вимогам

| Вимога | Реалізація |
|---|---|
| **Мова розробки** | Kotlin 2.0, Android Views (Custom Canvas `BoardView`, Material Design 3) |

## Як грати та керувати

1. **Управління на полі**:
   - **Один дотик** по прихованій клітинці — поставити або зняти прапорець.
   - **Подвійний дотик** по прихованій клітинці — відкрити її.
   - **Подвійний дотик** по відкритому числу — виконати «chord» (відкрити всіх прихованих сусідів, якщо кількість встановлених навколо прапорців відповідає даному числу).
2. **Панель меню (⋮)**:
   - **Тема** — відкриває діалог вибору одного з 5 варіантів оформлення з попереднім переглядом.
   - **Прапорці** — дозволяє змінити колір прапорця на свій смак.
   - **Мова** — перемикання мови інтерфейсу (English, Українська, עברית).
3. **Керування складностями та рестартом**:
   - Кнопка складності вгорі дозволяє швидко обрати рівень: **Новачок** (9×9, 10 мін), **Середній** (16×16, 40 мін) або **Експерт** (16×30, 99 мін).
   - Кнопка **Скинути** (Restart) розпочинає нову партію на поточному рівні.

## Алгоритм Solver-а

Розв'язувач аналізує лише публічний стан поля (`BoardSnapshot`). Алгоритм послідовно застосовує 4 рівні аналізу від простих до складних:

1. **Просте правило (Simple Rule)**:
   - Якщо у відкритої клітинки з числом $N$ є рівно $N$ закритих сусідів — усі вони є мінами.
   - Якщо у числа 0 прихованих сусідів, що залишилися — вони всі безпечні.
2. **Правило підмножин (Subset Rule)**:
   - Якщо множина прихованих сусідів числа A є підмножиною сусідів числа B, то різниця між ними визначається значенням $B - A$. Це дозволяє вирішувати складні комбінації (наприклад, класичний шаблон 1-2-1).
3. **Точний перебір обмежень (CSP Enumeration)**:
   - Межові приховані клітинки (*frontier*) розбиваються на незалежні зв'язні компоненти.
   - Для кожної компоненти шляхом бектрекінгу перебираються **всі** узгоджені варіанти розташування мін (з обмеженням у 300 000 вузлів на компоненту).
   - Результати об'єднуються з глобальним лічильником мін через комбінаторику з використанням `BigInteger`. В результаті обчислюється точна ймовірність наявності міни в кожній прихованій клітинці (0.0 — гарантовано безпечна, 1.0 — гарантовано міна).
4. **Аналіз ризику та здогад (Smart Guessing)**:
   - Якщо гарантованих ходів немає, вибирається прихована клітинка з найменшою ймовірністю міни.
   - При рівній ймовірності перевага надається кутовим та крайовим клітинкам, оскільки вони мають вищий шанс відкрити нульову область та розкрити більше інформації.

## Логування

Логування побудоване на базі бібліотеки **Timber**:
- У **Debug-режимі** використовується `LineNumberDebugTree`, що виводить у Logcat clickable посилання на клас і номер рядка (наприклад, `MainActivity:142`).
- У **Release-режимі** діє `ReleaseTree`, яке відфільтровує налагоджувальні логи і пропускає лише сповіщення рівня `WARN` та `ERROR`.
- Логування працює у всіх шарах застосунку, включаючи модуль чистої логіки гри та розв'язувача.

## Інтернаціоналізація (i18n)

- Усі текстові ресурси розміщено у `values/strings.xml`, `values-uk/strings.xml` та `values-iw/strings.xml`.
- Для числівників використано ресурсну систему `plurals` з урахуванням специфіки мов (наприклад, 4 форми для української мови та специфічні форми для івриту).
- Назви мов в інтерфейсі відображаються мовою оригіналу (`English`, `Українська`, `עברית`), щоб користувач міг легко зорієнтуватися при зміні налаштувань.
- Для івриту реалізовано повну підтримку режиму **RTL** (`android:supportsRtl="true"`).

## Тестування

Проєкт містить розширений комплект автоматизованих юніт-тестів для JVM:
- `BoardTest`:
  - Гарантія безпечності першого ходу.
  - Точність генерації кількості мін та відсутності мін у старті.
  - Коректність роботи Flood Fill, прапорців, акордингу.
  - Збереження приватності прихованих клітинок у `BoardSnapshot`.
- `MinesweeperSolverTest`:
  - Перевірка роботи простих правил, правил підмножин та шаблонів 1-2-1.
  - Перевірка CSP-перебору та обчислення ймовірностей.
  - **Автоматизований стрес-тест**: симуляція розв'язання 150 випадкових партій для перевірки того, що жоден «певна хід» Solver-а не призводить до підриву міни.
